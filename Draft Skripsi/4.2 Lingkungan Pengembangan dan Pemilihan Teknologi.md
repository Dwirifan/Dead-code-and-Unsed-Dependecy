# 4.2 Lingkungan Pengembangan dan Pemilihan Teknologi
Pengembangan dan pengujian utilitas ini membutuhkan lingkungan komputasi yang memadai serta pemilihan stack teknologi yang presisi. Pemilihan teknologi disesuaikan dengan kebutuhan sistem sebagai utilitas analisis statis berbasis Node.js yang memerlukan pemrosesan Abstract Syntax Tree (AST), antarmuka Command Line Interface (CLI), serta laporan visual berbasis HTML.

### 4.2.2 Lingkungan Eksekusi Dasar (Base Environment)

### 4.2.3 Core Engine & AST Processing
Lapisan Core Engine digunakan untuk memproses kode sumber tanpa menjalankan program target. Pada implementasi final, sistem menggunakan @typescript-eslint/typescript-estree sebagai parser engine utama karena mampu memproses sintaks JavaScript dan TypeScript menjadi representasi Abstract Syntax Tree (AST).

AST yang dihasilkan dari proses parsing digunakan sebagai dasar untuk menelusuri struktur kode, membaca deklarasi, mengidentifikasi relasi antarbagian kode, serta mendukung proses analisis terhadap elemen yang berpotensi tidak digunakan. Dengan pendekatan ini, sistem dapat melakukan analisis tanpa perlu mengeksekusi aplikasi target.

Selain @typescript-eslint/typescript-estree, sistem juga menggunakan estraverse dan magic-string sebagai pustaka pendukung. estraverse digunakan untuk membantu proses penelusuran node pada AST, sedangkan magic-string digunakan untuk mendukung manipulasi kode secara lebih terkontrol. Pemilihan pustaka tersebut disesuaikan dengan kebutuhan sistem yang melakukan analisis statis terhadap proyek JavaScript/TypeScript modern.

### 4.2.4 Manajemen Berkas & Lapisan Antarmuka Terminal
Sistem menggunakan beberapa pustaka pendukung untuk membaca struktur proyek, mengelola berkas, dan membangun antarmuka CLI. Pustaka fast-glob digunakan untuk memindai berkas berdasarkan pola ekstensi tertentu, sedangkan fs-extra digunakan untuk operasi berkas seperti membaca, menulis, menyalin, dan membuat cadangan.

Pada lapisan CLI, commander digunakan untuk mengelola perintah dan argumen terminal, sedangkan inquirer digunakan untuk menampilkan dialog konfirmasi pengguna sebelum proses penghapusan dilakukan. Selain itu, chalk digunakan untuk memberikan penanda warna pada keluaran terminal, dan ora digunakan untuk menampilkan indikator proses saat sistem berjalan.

### 4.2.5 Dashboard Pelaporan Visual
Sistem menyediakan laporan visual berbasis HTML untuk membantu pengguna meninjau hasil analisis. Laporan ini dibangun menggunakan HTML, CSS, dan JavaScript agar dapat dibuka langsung melalui peramban tanpa memerlukan server lokal.

Untuk visualisasi graf, sistem menggunakan Cytoscape.js dan Dagre. Cytoscape.js digunakan untuk menampilkan simpul berkas dan relasi dependensi antarmodul, sedangkan Dagre digunakan untuk menyusun tata letak graf agar lebih rapi dan mudah dipahami.

### 4.2.6 Alat Pendukung Pengembangan
Proses pengembangan didukung oleh Antigravity IDE, Git, GitHub, dan ESLint. Antigravity IDE digunakan sebagai lingkungan utama untuk menulis dan menyunting kode program. Git dan GitHub digunakan untuk mengelola versi kode sumber serta menyimpan repositori proyek.

Dalam penelitian ini, Git juga digunakan untuk mendukung pengelolaan tiga baseline kerja, yaitu development baseline, refactor baseline, dan production baseline. Penggunaan baseline tersebut mengacu pada penyesuaian praktik XP untuk pengembang tunggal, sehingga perubahan kode dapat dikontrol secara bertahap sebelum ditetapkan sebagai versi stabil [21]. Sementara itu, ESLint digunakan untuk membantu menjaga konsistensi dan keterbacaan kode selama proses pengembangan.
