### 4.3.4 Perancangan Alur Sistem
Alur kerja sistem dirancang menggunakan arsitektur pipeline yang beroperasi secara sekuensial dan semi-otomatis. Perancangan alur sistem ini dibagi menjadi dua bagian, yaitu diagram arsitektur pipeline yang menjelaskan aliran data antar-modul, serta activity diagram CLI yang menjelaskan urutan interaksi pengguna dengan sistem.

**A.   Diagram Arsitektur Pipeline**
Diagram arsitektur pipeline menggambarkan aliran data mulai dari eksekusi perintah utilitas analisis melalui Command Line Interface (CLI), pembacaan berkas sumber, pembentukan Abstract Syntax Tree (AST), pembangunan dependency graph, hingga proses analisis menggunakan algoritma BFS. Melalui alur ini, sistem dapat memisahkan berkas aktif dari berkas mati serta mengidentifikasi dead code dan dependensi yang tidak digunakan.

Pada tahap penindakan, sistem tidak langsung melakukan penghapusan. Sistem terlebih dahulu menampilkan ringkasan temuan dan meminta konfirmasi pengguna melalui prompt interaktif untuk mengurangi risiko false positive, terutama pada kode yang menggunakan dynamic imports atau pola pemanggilan saat runtime. Apabila pengguna menyetujui, Modul Eliminator akan memproses kode sesuai dengan tingkat eliminasi yang dipilih, membersihkan dependensi tidak terpakai dari manifes proyek, membuat backup, dan menyelesaikan proses eksekusi. Aliran data antar-modul tersebut ditunjukkan pada Gambar 4.5.
